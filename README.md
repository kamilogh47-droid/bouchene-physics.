# Bouchene Kamel – Physics (تطبيق متابعة الطلاب وتسجيل الحضور)

تطبيق أندرويد (Kotlin + Jetpack Compose + Room + Hilt) للأستاذ Bouchene Kamel.

## التشغيل
1. ثبّت **Android Studio** (إصدار Koala أو أحدث) مع JDK 17.
2. افتح مجلد `BouchenePhysics` عبر File ▸ Open، وانتظر مزامنة Gradle.
3. شغّل التطبيق على هاتف أو محاكي (Android 8.0 / API 26 فأعلى).
4. الرمز السري التجريبي: **1234** (المساعد: 0000).

> ملاحظة: مجلد `gradle/wrapper` غير مضمّن. Android Studio ينشئه تلقائيًا عند أول مزامنة.

## ما أُنجز في هذه المرحلة
- الهوية: ألوان أزرق سماوي + ذهبي، أيقونة التطبيق، ثيم فاتح/داكن، نصوص عربية/إنجليزية/فرنسية مع RTL.
- قاعدة البيانات المحلية (Room): المستخدمون، الأفواج، الطلاب، الحضور، الدرجات + بيانات تجريبية.
- الشاشات: تسجيل الدخول بـ PIN، لوحة التحكم (إحصائيات اليوم)، تسجيل الحضور (4 حالات + "تحديد الكل حاضر" + تعديل سجل اليوم)، قائمة الطلاب (إضافة/حذف).

## المراحل القادمة
1. ماسح QR (ML Kit) لتسجيل الحضور.
2. ملف الطالب (نسبة الحضور والدرجات والملاحظات).
3. التقارير + الرسوم البيانية + تصدير PDF/Excel.
4. إدارة الأفواج وجداول الحصص، والبحث والتصفية.
5. مزامنة Firebase (Auth + Firestore) مع WorkManager.
6. تنبيهات تجاوز حد الغياب.

## بناء نسخة النشر
Build ▸ Generate Signed Bundle / APK ▸ Android App Bundle (AAB) ثم الرفع إلى Google Play Console.
